# Projeto de Compiladores - UFS

Este repositório foi criado para o desenvolvimento do projeto da disciplina de Compiladores da Universidade Federal de Sergipe (UFS). O objetivo é aplicar os conceitos teóricos estudados em sala de aula na construção de um compilador funcional, em etapas, seguindo as boas práticas de análise léxica, sintática e semântica.

## Objetivo do projeto

O projeto tem como finalidade:

- compreender o funcionamento de um compilador;
- implementar as etapas de análise de código;
- desenvolver uma linguagem simples ou um subconjunto de linguagem para teste;
- validar a estrutura do compilador com casos de entrada e saída esperados;
- consolidar os conhecimentos de teoria dos compiladores.

### Etapa 1
A pasta `etapa1/` representa a primeira fase do projeto, normalmente relacionada a:

- reconhecimento de tokens;
- análise léxica;
- identificação de palavras reservadas, identificadores, números e símbolos;
- estrutura inicial do compilador.
